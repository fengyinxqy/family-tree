技术栈与部署方案

选型原则：成熟稳定、生态丰富、部署简单

技术栈明细

层级 技术选型 说明
框架 Next.js 15 (App Router) React 全栈框架，Server Components + Server Actions
语言 TypeScript 类型安全，减少运行时错误
ORM Prisma 类型安全的数据库操作，自动 Migration
数据库 PostgreSQL 16 关系型数据库，支持复杂查询和事务
认证 NextAuth.js v5 JWT 会话，邮箱密码登录
树形图 React Flow 交互式节点图，支持自定义节点和布局
样式 Tailwind CSS 原子化 CSS，快速构建 UI
UI 组件 shadcn/ui 可定制的 React 组件库，与 Tailwind 深度集成
表单验证 Zod TypeScript 优先的 Schema 验证

🐳 Docker 部署方案

docker-compose.yml
📦 nextjs
Next.js 应用容器
端口: 3000
依赖: postgres
构建: Dockerfile (multi-stage)
🗄️ postgres
PostgreSQL 16 容器
端口: 5432
数据卷持久化
healthcheck 自检
docker compose up -d ← 一键启动
docker compose exec nextjs npx prisma migrate deploy ← 数据库初始化
