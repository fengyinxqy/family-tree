关键架构决策

多租户隔离

数据库级别通过 family_id 外键隔离，中间件注入当前家族上下文，确保请求只访问本家族数据

家谱树渲染

服务端加载家谱数据，客户端用 React Flow 库渲染交互式树形图。支持纵向/横向切换，拖拽缩放平移

Server Actions 混合策略

数据变更（增删改）使用 Server Actions 简化代码；数据查询使用 REST API 便于前端缓存和树形数据加载
