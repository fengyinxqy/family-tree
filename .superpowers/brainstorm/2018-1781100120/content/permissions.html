权限执行流程

用户请求 → Next Auth 中间件
验证登录态 → 家族上下文中间件
提取 familyId + 角色 → 权限守卫
角色 → 操作检查 → API / 页面

关键设计决策

家族创建者即首位管理员

创建家族时自动以 admin 角色加入 FamilyMember 表。创始人不可被降级或移除。

多层防护

前端 UI 隐藏操作按钮 + API 层角色校验 + 数据库查询带 family_id 过滤。三层防护，任一失败都不泄漏数据。

邀请制加入

管理员生成邀请链接（带过期时间），新用户通过链接注册后自动加入家族，默认角色为 viewer。
