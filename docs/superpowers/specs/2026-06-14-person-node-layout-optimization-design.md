# 人物卡片布局优化 — 设计文档

**日期**: 2026-06-14  
**状态**: 已批准  
**范围**: `src/components/person-node.tsx`

## 背景

家谱树图中的人物卡片（PersonNode）宽度为 190px，性别标签和生卒年份挤在同一行，年份文字因 `truncate` 截断而不可见。用户反馈看不到出生年月。

## 设计目标

- 生卒年份清晰可见，不被截断
- 保持卡片整体紧凑，不显著影响树图密度
- 不改动头像、姓名、箭头链接等已有布局

## 方案选择

**方案 B — 年份独立成行**。将性别标签和生卒年份从同一行拆为两行，卡片宽度微扩至 200px。

## 具体变更

### 文件: `src/components/person-node.tsx`

| 属性 | 当前值 | 新值 |
|------|--------|------|
| 卡片宽度 | `w-[190px]` | `w-[200px]` |
| 性别+年份行 | 同一行 `flex items-center gap-2` | 拆为两行 |
| 年份 `truncate` | `className="truncate"` | 去除 |
| 年份容器 | 无 | `className="text-xs text-muted-foreground mt-0.5"` |

### 布局对比

```
当前 (190px)                    目标 (200px)
┌────────────────────┐          ┌──────────────────────┐
│ 👤 张某某        →│          │ 👤 张某某          →│
│   [男] 1950-2005  │    →     │   [男]               │
└────────────────────┘          │   1950 - 2005        │
                                └──────────────────────┘
```

### 不改动

- 头像、姓名、箭头链接
- 男/女色系（`palette.frame`, `palette.border`, `palette.accent`）
- 选中高亮、世代高亮、hover 缩放
- Handle 连接点位置
- 树图布局算法
